# 개선대책서 — 필러트림 클립 파손 (QIR-2023-0288)

## 현상
2023년 3월 I차종 필러트림 조립 시 클립이 체결 중 파손되는 불량이 급증하였다. 동일 작업·동일 토크임에도 특정 입고분 클립에서만 파손이 집중되었다.

## 원인 분석
작업 조건은 동일했으나 파손이 특정 입고분에 집중된 점에서 부품 요인을 의심하였다. 조사 결과 클립 **공급사가 변경**되면서 재질 등급이 미세하게 달라져 강성·인성이 저하되었고, 체결 응력에 취약해져 파손된 것이 귀책사유로 확정되었다. 공급사 변경 시 규격 재검증 절차가 누락되었다.

## 대책방안
1. 변경된 공급사 클립 재질·강도 **규격 재검증**(인장·체결 시험).
2. 수입검사에 클립 강도 샘플 시험 항목 추가.
3. 부품 공급사 변경 시 **4M 변경점 관리** 승인 절차 의무화.

## 실시 결과
클립 파손 불량 재발 0건. 공급사 변경 관리 프로세스가 보완되었다.
