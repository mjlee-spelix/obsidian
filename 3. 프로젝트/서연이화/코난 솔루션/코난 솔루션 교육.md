컬렉션별로 데이터 검색까지

데이터 수집 -> 전처리, 청킹, 임베딩, 색인, 품질 검증

수집: pdf->문서->청킹 과정으로 데이터 가져옴
대량 작업 탭에서 문서 삭제 가능(원본 구조 변경되지 않는 이상 수집에서 제외됨)

컬렉션별로 청킹 전략
- 전략 저장하고 전략 수행 해야 전체 컬렉션에 적용 됨

컬렉션 유형 문서/db/fgf?

- 중복 파일 제외, 파일 크기 지정 가능

db
- db 접속하려면 테이블 지정해야 되나, pk 등 필수 필드 매핑해야
- db 소스 설정할 때 테이블 조회 해야 소스 가져옴, 이후에 테이블 선택하고 필드 설정해야 함, 추가로 가져오고 싶은 정보는 메타데이터로 가져옴

컬렉션 내에서 대표 지식 지정하면 이거로 청킹 미리보기 할 수 있음(100페이지에 15~20초) 
청킹 방식은 시맨틱 지원 안하고 사이즈만 가능

청킹 편집: 청킹 직접 삽입/분할 가능(mdx뷰어로보면서), 수동적으로
청킹 비교: 최신 3가지 버전의 청킹 전략 비교

db 는 색인 전략에서 커스텀 필드로 색인 설정 가능(마스킹 처리 등)
index wizard랑 동일한 기능?
