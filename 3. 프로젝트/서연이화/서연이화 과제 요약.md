## 과제 1: 인사 정보 기반 권한 자동 맵핑
#초중급 
- **핵심사항**
	- 그룹웨어의 인사 이동 정보(부서 이동 등)를 일배치로 받아와, 업무 시스템(플랫폼) 내 사용자 권한을 자동으로 변경해주는 규칙 기반(Rule-based) 모델을 구축하는 것입니다.
- **액션 플랜**
	- 고객사가 제공하는 권한 부여 기본 정책 및 예외 케이스를 분석하여 룰베이스 엔진을 개발하고, 에이전트 관리 도구와 연동합니다.
- **참고**
	- 100% 룰베이스 과제이므로 Python 스크립트나 Spring 스케줄러(Cron) 활용이 훨씬 효율적

## 과제 2: 현대차 업무 포털 단가 조회 자동화 (매크로)
#초중급 
- **핵심사항**
	- 매일 사람이 현대차 포털에 로그인해 미결 품목을 조회하고 단가를 엑셀로 정리하여 업로드하는 반복 작업을 자동화하는 것입니다.
- **액션 플랜**
	- 크롬 기반의 웹 매크로를 활용해 미결 품목 및 단가를 스크래핑한 뒤, 엑셀 텍스트를 파싱하여 자사 플랫폼으로 일괄 전송하는 프로세스를 개발합니다.
- **참고**
	- 크롬 기반 웹 매크로, Python(Selenium 등) 또는 범용 RPA 도구 사용이 필수적

## 과제 3: 기술 표준 문서 LLM 요약 및 비교
#중급 
- **핵심사항**
	- 각 100여 장에 달하는 비정형 기술 표준 문서를 LLM을 활용해 중요한 시험 리스트 위주로 요약하고, 과거 버전과 최근 버전 간의 세부적인 기술 표준 차이를 비교 분석하는 기능입니다.
- **액션 플랜**
	- 비정형 문서를 OCR로 구조화한 후(전처리 업체 수행), 추출된 텍스트를 기반으로 핵심 정보를 요약하고 연도별 변경점을 도출하는 LLM 프롬프트를 설계합니다.
- **참고**
	- 전처리 업체(한국딥러닝)의 파싱 품질이 결과의 90%를 좌우

## 과제 6: 과거 대책서 기반 유사 사례 검색 및 대책 생성
#중고급 
- **핵심사항**
	- 약 7천~1만 건의 PPT 형태 과거 대책서 데이터를 전처리하여, 사용자가 현재의 '현상'과 '원인'을 입력하면 가장 유사한 과거 사례를 검색(RAG)해 새로운 대책 보고서 텍스트를 구조화하여 생성해 주는 과제입니다.
- **액션 플랜**
	- 전처리 업체(한국딥러닝) 및 고객사와 협의해 과거 대책서의 DB 스키마(현상, 원인, 대책 등)를 명확히 구조화하고, 이슈 타입이나 품명별로 검색 볼륨을 나누어 RAG의 검색 품질과 프롬프트를 고도화합니다.
- **참고**
	- 청킹(Chunking) 룰 세팅이 품질의 관건

## 과제 11: 컬러 사양표 자동 입력 및 품명 오타 보정
#중급
- **핵심사항**
	- 고객이 주는 비정형 컬러 사양표(엑셀, PPT)에서 부품별 컬러 값을 플랫폼에 자동 기입하는데, 고객사의 품명에 오타가 섞여 있어도 AI가 이를 보정하여 정확한 부품에 맵핑해 주어야 합니다.
- **액션 플랜**
	- 전처리 업체로부터 텍스트를 전달받아, 동의어 사전이나 단어 유사도 알고리즘을 적용해 오타를 매핑합니다. 유사도가 애매한 경우(예: 85%) 드롭박스를 통해 사용자가 최종 선택할 수 있도록 UI 옵션을 협의합니다.
- **참고**
	- Python 문자열 유사도 라이브러리나 동의어 사전

## 과제 12: 신규 프로젝트 금형 수축률 AI 추천
#고급 
- **핵심사항**
	- 원소재 업체, 재료, 생산 공장 등 과거 데이터를 기반으로 신규 프로젝트 시뮬레이션을 돌리기 전에 AI가 미리 최적의 금형 수축률을 추천해 주는 기능입니다.
- **액션 플랜**
	- 초기 양산 수축률뿐만 아니라 이후 품질 이슈로 인해 튜닝된 수축률 데이터까지 플랫폼에서 취합할 수 있는 방안을 기획하고, 이를 기반으로 추천 알고리즘을 적용합니다.
- **참고**
	- 수치형 데이터 예측 모델링이므로 LLM 대신 Scikit-learn, XGBoost 등 머신러닝 회귀 모델이 필요

## 과제 13: 표준 품명 규칙 치환 및 공법 추천
#중급 
- **핵심사항**
	- 설계 담당자마다 다르게 텍스트로 치는 품명(예: DT K8 레프트)을 새롭게 제정할 표준 품명 규칙(예: K8_LH_V2)으로 자동 치환하고, 모호한 부품 공법 선택 기준을 과거 사용 빈도(예: 8대2 비율) 기반으로 추천합니다.
- **액션 플랜**
	- 고객사와 함께 현재 20%만 완성된 표준 품명 규칙을 확립하고 치환 엔진을 적용합니다. 공법 추천은 추후 상관 분석 및 회귀 분석을 통해 변수 가중치를 조절하는 방식으로 고도화를 검토합니다.
- **참고**
	- 통계 기반의 공법 추천은 일반 수학/통계 함수로 구현하는 것이 더 효율적

## 과제 14: 원소재 업체 및 양산처 자동 맵핑
#중급 
- **핵심사항**
	- 그룹웨어의 대내문(HTML) 제목과 간단한 표 정보만으로 어떤 제품의 원소재 공급 및 양산 업체인지를 추정하여 플랫폼에 자동으로 기입합니다.
- **액션 플랜**
	- 현재의 HTML 문서 내용만으로는 제품 매칭 정보가 부족할 위험이 크므로, 이메일 수신처나 추가 문맥 정보를 활용해 정확히 맵핑하는 규칙을 고객사와 심도 있게 사전 협의하여 확정합니다.
- **참고**
	- 정보 파편화가 심하고 문맥 추론이 필요하여 LLM 활용이 좋으며, HTML 태그 전처리가 동반되어야
