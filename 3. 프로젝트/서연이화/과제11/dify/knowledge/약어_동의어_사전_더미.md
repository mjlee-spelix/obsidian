# 약어·동의어 사전 (더미) — 과제11 S-SPC 부품 컬러 사양 자동 추출

> **Dify 지식 등록 안내**
> - 데이터셋 이름 예: `약어·동의어 사전` → 생성 후 데이터셋 ID를 앱 YAML의 `REPLACE_WITH_DATASET_ID_약어동의어사전`에 교체.
> - 임베딩 모델: `bge-m3-ko`. 검색: 벡터 검색, top_k 10.
> - 청킹: **구분자 `---` 기준 표제어당 1청크.** 부품명 정규화(2차 매칭) 시 약어→정식명 치환 근거로 사용됩니다.
> - JSON 블록의 `abbr`/`full`/`synonyms`를 매칭 code 노드가 참조합니다.
