# LangGraph 핵심 개념 - State, Node, Edge

> 이 3개 + Checkpointer면 LangGraph의 80%. 나머지는 응용.

## 핵심
- LangGraph는 에이전트 워크플로우를 **그래프**로 모델링한다. 3대 구성요소:
  - **State**: 그래프 전체가 공유하는 데이터 스냅샷 (보통 TypedDict/스키마)
  - **Node**: 실제 일을 하는 함수. State를 받아 **갱신할 부분만** 반환
  - **Edge**: 다음에 어떤 Node로 갈지 결정 (고정 전환 or 조건부 분기)
- 한 줄 요약: **"노드는 일을 하고, 엣지는 다음에 뭘 할지 정한다."**
- Node/Edge는 결국 그냥 함수 → 안에 LLM을 넣든 평범한 코드를 넣든 자유.

## 상세
가장 단순한 그래프 (Python):
```python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    # State를 통째로 바꾸지 말고, 갱신할 key만 반환
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")   # 시작 → 노드
graph.add_edge("mock_llm", END)     # 노드 → 끝
graph = graph.compile()             # compile 해야 실행 가능

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```

기억할 규칙:
- 노드는 State를 **직접 수정(mutate)하지 말고**, 바꿀 부분만 dict로 반환한다.
- `messages` 같은 필드는 **reducer**가 알아서 이어붙인다(덮어쓰기 아님).
- `START` → ... → `END` 로 흐름을 정의하고, 마지막에 `.compile()`.
- 실행은 `graph.invoke(초기State)` — 결과로 **전체 State**를 돌려준다.

### 내부 동작 (한 번만 이해하면 됨)
- LangGraph는 **메시지 패싱** 기반 (Google Pregel에서 영감).
- 실행은 **super-step** 단위로 진행: 노드가 끝나면 엣지로 메시지를 보내고, 받은 노드가 활성화되어 실행. 더 이상 전달할 메시지가 없으면 종료.
- 병렬 노드 = 같은 super-step, 순차 노드 = 다른 super-step.
