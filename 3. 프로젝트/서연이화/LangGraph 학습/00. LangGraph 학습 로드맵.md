# LangGraph 학습 로드맵

이 폴더는 LangGraph를 처음부터 익히기 위한 학습 허브입니다.
개념 하나당 노트 하나(atomic)로 쪼개서, 그래프 뷰로 연결해 복습하기 좋게 구성했습니다.

## 핵심
- LangGraph = LLM 워크플로우를 **그래프(State + Node + Edge)** 로 모델링하는 프레임워크
- 체인(Chain)만으로는 어려운 **반복 / 분기 / 사람 개입 / 상태 저장**을 다루기 위해 나옴
- 공식 문서 기준 표준 학습 순서: **설계법 → 핵심 개념 → 조건부 흐름 → 상태 저장(메모리)**

## 프레임워크 공부 원칙 (LangGraph에도 그대로 적용)
- **"이게 없으면 뭐가 불편한가?"** 부터 이해 → LangGraph는 복잡한 흐름 제어의 고통을 해결
- 핵심 추상화 3~5개만 먼저 잡기 → 나머지는 그 위의 응용
- 문서 정독 < **작은 예제 직접 실행하고 에러 내보기**
- 어느 정도 쓰면 내부 원리(메시지 패싱/super-step) 한 번 들여다보기
