# LangGraph 조건부 엣지와 분기

> LangChain 체인과 LangGraph를 가르는 핵심 차이. **반복과 분기**가 여기서 나온다.

## 핵심
- **고정 엣지(`add_edge`)**: 항상 정해진 다음 노드로 간다. (A → B)
- **조건부 엣지(`add_conditional_edges`)**: 현재 State를 보고 **어디로 갈지 함수가 결정**한다.
- 이걸로 **분기(if/else), 반복(loop), 조기 종료**를 표현 → 복잡한 에이전트가 가능해짐.

## 상세
개념 구조 (Python):
```python
def route(state) -> str:
    # State를 보고 다음 노드 "이름"을 문자열로 반환
    if state["urgency"] == "high":
        return "human_review"
    return "draft_reply"

graph.add_conditional_edges(
    "classify_intent",   # 이 노드가 끝난 뒤
    route,               # 이 함수로 다음 노드를 결정
)
```

패턴 예시:
- **분기**: 의도 분류 노드 → (질문이면) 문서검색 / (버그면) 이슈등록 / (복잡하면) 사람검토
- **반복(loop)**: "답변이 충분한가?" 노드 → 부족하면 다시 검색 노드로 되돌림 → 충분하면 END. (엣지가 이전 노드를 다시 가리키면 루프)
- **에이전트 패턴(ReAct)**: LLM 노드 → 툴 호출이 필요하면 tool 노드로, 아니면 END로. 이게 바로 조건부 엣지의 대표 활용.

핵심 감각:
- "어디로 갈지"의 **결정 로직은 라우터 함수 안**에 있고, 엣지 다이어그램의 화살표는 "가능한 경로"만 그린다.
- 루프를 만들 수 있으니 **종료 조건(END로 가는 분기)** 을 반드시 넣어야 무한 반복을 막는다.
