# LangGraph 실습 로드맵과 참고 링크

> 읽기만 하면 안 남는다. **직접 타이핑하고 에러 내보기**가 진짜 학습.

## 핵심
- 개념 → 곧바로 손으로 만들어보며 체화한다. 아래 순서로 난이도를 한 단계씩 올린다.

## 실습 단계 (한 단계씩 직접 코딩)
1. **Hello World 그래프**: 노드 1개 + `START`/`END`. `.compile()` → `.invoke()` 흐름 익히기
2. **멀티턴 챗봇**: `MessagesState` + LLM 노드. Checkpointer 붙여 대화 기억 → [[04. LangGraph Checkpointer와 상태 저장]]
3. **조건부 분기 추가**: 입력을 분류해서 다른 노드로 라우팅 → [[03. LangGraph 조건부 엣지와 분기]]
4. **툴 호출 에이전트(ReAct)**: LLM이 툴을 부를지 스스로 결정, tool 노드 ↔ LLM 노드 루프
5. **Human-in-the-loop**: 특정 지점에서 멈춰 사람 승인 후 재개
6. **(심화) 멀티 에이전트 / 서브그래프**: 에이전트별 독립 State를 서브그래프로 분리

## 환경 준비
```bash
# Python
pip install -U langgraph langchain
# (LLM provider SDK는 별도 설치 — 예: anthropic 등)
```
