> 작성: 2026-06-13 · 대상: Docusaurus 문서 사이트(`ko/` 빌드)
> 산출물: 본 설계안(md) + `ui-redesign-prototype.html`(동작 프리뷰)
>
> **⚠️ v2 방향 전환 (2026-06-14, 프로토타입 검토 반영):** 초안의 "노드 원형 마커"(사이드바·TOC·h2 앞 동그라미)는 **전면 제거**하기로 함. 대신 **Docusaurus 기본 구조(접이식 그룹 + 좌측 보더 레일)를 유지**하고 그 위에 **인디고-슬레이트 테마 + Pretendard + 절제된 여백**으로 정체성을 입힌다. 정체성의 출처는 여전히 로고(헤더 노드 마크 + 인디고 색)이되, UI 위젯을 노드 그래프로 비유하던 시그니처는 폐기. 아래 §4·§5의 "노드 레일/모션" 서술은 이 전환으로 무효(헤더 로고 마크만 잔존).

## 0. 한 줄 요약

현재 사이트는 **Mintlify "maple" 테마를 픽셀 복제**한 상태다(일렉트릭 블루 `#0060FF` + Inter 단일 폰트). 이는 어느 SaaS 문서에나 붙는 제너릭 기본값이며 **SPX Agent 로고(인디고 노드 그래프)와도 색이 어긋난다.** 본 설계는 **로고의 노드-그래프 정체성을 문서 구조로 끌어와** 제품과 한 몸처럼 보이는 기술 문서 테마로 교체한다.

---

## 1. 진단 — 지금 무엇이 제너릭한가

| 항목 | 현재 | 문제 |
|------|------|------|
| Primary | `#0060FF` (Mintlify maple) | 로고 인디고 `#6366F1`와 불일치. 출처가 제품이 아니라 템플릿 |
| 폰트 | Inter 단독 | 문서 사이트의 최빈 기본값. 개성 0 |
| 사이드바 마커 | 밋밋한 `border-left` 1px | 구조를 "장식"할 뿐, 제품의 무엇도 인코딩하지 않음 |
| 전반 인상 | "Mintlify로 만든 문서" | "SPX Agent 문서"라는 신호가 로고 말곤 없음 |

핵심: **시각 정체성의 출처가 제품이 아니라 템플릿이다.** SPX Agent의 세계(에이전트 = 노드로 연결된 워크플로, 로고 = 노드 그래프, 화면 = 대시보드·감사로그·권한 그래프)에서 단 하나도 디자인으로 들어오지 않았다.

---

## 2. 디자인 논지 (Thesis)

> **문서를 제품처럼 보이게 한다.** SPX Agent는 노드를 잇는 에이전트 오케스트레이션 플랫폼이고, 로고는 글자 그대로 노드 그래프다. 문서의 내비게이션·목차·섹션 마커를 **노드와 연결선(rail)** 의 어휘로 재구성해, 읽는 행위가 그래프의 경로를 따라가는 경험이 되게 한다.

이건 장식이 아니라 주제에서 파생된 구조다 — 사이드바 트리는 실제로 그래프이고, 읽기 위치는 실제로 경로다.

## 3. 토큰 시스템

### 3.1 컬러 — 로고에서 직접 추출 (Mintlify `#0060FF` 폐기)

```
인디고 (브랜드 = 로고 노드 색)
  --indigo-600  #4F46E5   강조·active·hover 깊은 톤
  --indigo-500  #6366F1   PRIMARY (로고 중앙 노드)
  --indigo-400  #818CF8   다크모드 노드·보조
  --indigo-300  #A5B4FC   다크모드 코너 노드
  --indigo-50   #EEF0FE   soft 틴트 배경

잉크 & 슬레이트 (로고 연결선·워드마크 색)
  --ink         #1E2230   제목 (워드마크 #1A1A1E 계열, 푸른기 살짝)
  --ink-700     #3A4053   본문
  --slate-400   #94A3B8   muted·캡션
  --slate-300   #CBD5E1   RAIL·보더 (로고 스포크 색 그대로)
  --slate-200   #E2E8F0   약한 구분선

지면
  --paper       #FBFBFD   페이지 배경 (순백 아님 — 차가운 near-white = 기술적)
  --surface     #FFFFFF   카드·코드·표면
```

**다크 모드** (로고 white 버전 색 사용)
```
  --paper  #0B0D12   --surface #12151C   --ink #F8FAFC
  --rail   #475569 (로고 다크 스포크)   --node #818CF8
```

근거: cream+serif+terracotta / near-black+acid-green / 브로드시트 하어라인 — AI가 주제 무관하게 뱉는 3대 기본값을 **모두 회피**. 차가운 인디고-슬레이트는 "내부 운영 도구 / 엔지니어링 시스템" 정체에서 나온 선택이며 로고와 1:1로 묶인다.

### 3.2 타이포 — 3역할, 한국어 우선

| 역할 | 폰트 | 근거 |
|------|------|------|
| 본문·제목 | **Pretendard** | 한국어 문서. Hangul+Latin을 한 패밀리로 정교하게. Inter보다 한글 렌더링이 압도적 |
| 유틸리티(**영문/숫자** eyebrow·코드·KPI 단위·필드 타입) | **IBM Plex Mono** | 운영·기술 시스템 악센트. 노드 ID·코드와 한 결 |
| 코드 | IBM Plex Mono | 유틸리티와 통일 (현재 JetBrains Mono 대체) |

> 한국어 docs라 헤딩에 화려한 Latin serif(=클리셰, 게다가 한글 불가)를 쓰지 않는다. 제목은 Pretendard의 weight·tracking으로 절제 있게 무게를 준다.
>
> **⚠️ 프로토타입 1차 검증으로 교정된 규칙 (중요):** 모노 + 양수 `letter-spacing` + `uppercase`는 **영문/숫자에만** 적용한다. **한글 라벨에 씌우면 자간이 깨진다**(예: "전 체  사 용 자"). 한국어 문서는 라벨 대부분이 한글이므로 **타이포 시그니처를 모노에 의존할 수 없다** — 개성은 언어 중립적인 **노드 레일**이 주도하고, 모노는 영문/숫자 악센트로 보조한다. 한글 라벨(그룹명·KPI 라벨·TOC 라벨)은 Pretendard + 음수/기본 자간을 쓴다.

타입 스케일 (tracking은 제목에 `-0.02em`):
```
eyebrow   13px / mono / 600 / letter-spacing 0.08em / UPPERCASE 느낌(영문 라벨)
h1        30px / 700 / -0.02em
h2        22px / 650 / -0.015em
h3        18px / 600
body      16px / 400 / line-height 1.75
caption   13px / mono / slate-400
```

### 3.3 레이아웃

3컬럼 골격은 유지(사이드바 304px · 본문 · TOC)하되 **여백·라인의 정밀도**로 승부. 본문 폭 ~680px. 페이지 상단 eyebrow는 모노로 `섹션 / 위치`를 노드 좌표처럼 표기.

```
┌──────────────┬─────────────────────────────┬───────────────┐
│  ● 로고/검색  │  WORKSPACE · 사용자·부서 관리  │  이 페이지 (TOC)│
│              │                             │               │
│  ● 워크스페이스 │  # 사용자·부서 관리          │  ● 개요        │
│  │ 기본 설정   │  ─ description ─            │  │ 부서 만들기  │
│  ● 사용자·부서 │                             │  ● 멤버 배정    │  ← 읽기 위치
│  │ 권한 설정   │  본문 …                      │  │ KC 그룹 연동 │
│  ● 통계·감사   │  [KPI 카드 행]               │               │
│              │  [Note 콜아웃] [코드]         │               │
└──────────────┴─────────────────────────────┴───────────────┘
   ▲ node-rail        ▲ mono eyebrow              ▲ node-rail
```

## 4. 시그니처 — "노드 레일 (Node Rail)"

페이지를 단 하나로 기억시키는 요소.

- 사이드바 그룹 헤더 = **채워진 인디고 노드**(로고 중앙 노드 미니어처). 하위 항목은 **연결선(rail, slate-300)** 위에 작은 노드 점으로 매달림.
- **active 항목**: 노드가 인디고로 점등 + 그룹 노드→현재 노드까지 rail 구간이 인디고로 **트레이스(경로 추적)**. 그래프에서 한 경로가 켜지는 모습 그대로.
- 우측 TOC도 동일 어휘 — 스크롤하면 읽는 위치의 노드가 차례로 점등.

> 로고가 노드 그래프이고 제품이 노드 워크플로이므로, 이 시그니처는 **장식이 아니라 제품 표면의 연장**이다. 숫자 마커(01/02/03)를 쓰지 않는 이유: 내비는 시퀀스가 아니라 그래프다(반대로 Steps 컴포넌트는 진짜 순서라서 숫자 유지).

---

## 5. 모션 — 절제된 한 순간

- **페이지 로드**: 사이드바 rail이 중앙 노드에서 아래로 그려지며(draw-in) active 노드가 마지막에 부드럽게 점등. 오케스트레이션된 단 하나의 순간.
- **호버**: 노드 점이 살짝 커지고 rail 구간이 옅게 밝아짐(미세 인터랙션).
- `prefers-reduced-motion`: 모든 트레이스/드로우 비활성, 상태색만 즉시 적용.

과한 모션은 AI 생성 느낌을 키우므로 위 3개로 한정한다.

## 6. 컴포넌트별 적용

| 컴포넌트 | 변경 |
|----------|------|
| 사이드바 | 노드 레일 시그니처 적용. 그룹 헤더에 인디고 노드 |
| TOC | 노드 레일 미러링, 스크롤 점등 |
| Callout(Info/Note/Tip/Warning) | 인디고 기준으로 Note 재조정, 좌측 4px 대신 노드 점 아이콘 정렬 |
| 코드블록 | 모노 IBM Plex, 차가운 surface, radius 12px 유지 |
| Frame | 기존 dot-grid 유지(주제와 일치) — 단 페이지 전역엔 안 깔고 Frame/Hero에 한정(Chanel: 액세서리 하나 빼기) |
| **KPI 카드(대시보드 챕터)** | 숫자=Pretendard tabular, 단위·델타=모노, 노드 점 악센트. 데이터 챕터 정체성 강화 |
| Steps | 진짜 시퀀스 → 숫자 마커 유지(노드 점 아님) |
| Pagination | radius·hover ring 유지, 색만 인디고 |

## 7. AI 기본값 자기검증 (skill 요구)

| 클리셰 | 회피 여부 |
|--------|----------|
| 크림+세리프+테라코타 | ✅ 차가운 인디고-슬레이트 |
| near-black + 애시드 그린 | ✅ 해당 없음 |
| 브로드시트 하어라인/신문 컬럼 | ✅ 하어라인은 쓰되 노드-그래프 시그니처로 차별화, 신문 레이아웃 아님 |
| 숫자 마커 01/02/03 남용 | ✅ 내비=그래프라 노드 점 사용. 숫자는 진짜 시퀀스(Steps)만 |
| Inter 단일 폰트 | ✅ Pretendard + IBM Plex Mono 유틸리티 레이어 |

**감수한 리스크 1개**: docs에 모노 유틸리티 레이어 + 노드 레일을 정체성으로 삼는 것(대부분 docs는 Inter로 안전하게 감). 정당화: 제품이 문자 그대로 노드-그래프 에이전트 빌더이고 로고가 노드 그래프다 — 문서는 제품 표면의 연장이어야 한다.

## 8. 구현 매핑 (`src/css/custom.css`)

원본 보존 원칙상 MDX 본문은 손대지 않고 **CSS 토큰 + 컴포넌트 스타일 + 소량의 swizzle**로 끝낸다.

1. `:root` 토큰 교체: `--ifm-color-primary` 계열을 인디고로, 폰트 변수 Pretendard/IBM Plex Mono로.
2. 폰트 로드: Pretendard CDN + IBM Plex Mono(Google Fonts). 기존 Inter/JetBrains import 제거.
3. `.menu` / `.table-of-contents` 노드 레일 스타일(::before 노드 점 + rail 트레이스).
4. `.page-eyebrow` 모노화. KPI 카드 유틸 클래스 신설.
5. 다크 토큰 동기화.

영향 파일: `src/css/custom.css`(주), `docusaurus.config.js`(로고 alt·prism 테마 색), 필요 시 `src/theme/DocSidebarItem` 미세 swizzle. **`docs.json`·원본 MDX·writing-guides 무수정** (fork 보존 원칙 준수).
