# Mintlify vs Docusaurus 디자인 비교 분석

> 분석 일자: 2026-06-02
> 기준: Mintlify 원본 (Dify docs) vs Docusaurus 전환 후 현재 상태

## 배경

Phase 3.5에서 Mintlify → Docusaurus 전환을 실행한 뒤, CSS 스타일링과 컴포넌트 swizzle로 Mintlify 디자인을 재현하는 작업을 진행했습니다. 1차 CSS 적용 후 Mintlify 원본 화면과 나란히 비교 스크린샷을 찍어 남은 차이를 영역별로 정리한 문서입니다.

**용도**: 추후 디자인 정교화 작업 시 참조용 체크리스트. 미수정 항목 표의 우선순위·난이도를 기준으로 작업 범위를 결정합니다.

## 1. 헤더 (Navbar)

| 요소 | Mintlify | Docusaurus (현재) | 일치 | 수정 가능성 |
|------|----------|-------------------|------|------------|
| 구조 | 상단 네비바 없음, 사이드바 헤더에 통합 | 전체 너비 상단 네비바 | ❌ | 대규모 swizzle 필요, 수용 |
| 검색 위치 | 사이드바 상단 | 네비바 우측 | ❌ | swizzle 필요, 현재 유지 |
| 로고 | 사이드바 좌상단 | 네비바 좌측 | △ | 위치만 다름 |
| Studio/토글 | 로고 옆 작은 아이콘 | 사이드바 하단 | △ | 네비바에서 빠진 건 OK |

| 요소 | Mintlify | Docusaurus (현재) | 일치 | 수정 가능성 |
|------|----------|-------------------|------|------------|
| 활성 항목 | 좌측 파란 세로선 + 연한 배경 | 좌측 파란 세로선 + 연한 배경 | ✅ | — |
| 카테고리 화살표 | 우측 끝에 작은 `>` | 좌측에 `▽` 셰브론 | ❌ | CSS |

| 아이템 아이콘 | 문서/폴더 아이콘 | 없음 | ❌ | swizzle |
