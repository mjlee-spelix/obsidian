## 사용법

1. 그룹 파일(예: [[01-시작하기]])을 열고, 검수할 페이지 섹션 아래에 발견사항을 **체크박스 + 태그**로 적는다.
2. 페이지 다 보면 그 페이지 상태를 `✅ 완료`로, `원문대조`까지 했으면 ☑로.
3. 그룹 다 보면 아래 매트릭스의 그룹 행을 갱신.
4. 발견사항 고치면 체크박스 `[x]`. 규칙이 될 만한 건 [[conventions]], 현황은 [[progress]]에 반영.

### 발견사항 형식
```
- [ ] #검수/직역체 (L23) "~을 위한 도구" → "~용 도구" / 어색

- [ ] #검수/질문 튜토리얼 카드 링크 3건 — 신규 챕터 작성 후 해소되는지 확인
```

## 검수 분류 프로세스 (까먹어도 유지되게)

> 그룹 검수가 끝나면 발견사항을 **그룹 파일 상단 4영역 코드블록**으로 분류하고, 전역성 있는 건 아래 [[#반영 대기 (검수 누적 → 마감 후 일괄 승격)|반영 대기]]에 누적한다. 각 그룹 파일 상단 코드블록이 이 절을 가리킨다.

1. **검수** — 그룹 파일에서 페이지별 발견사항 기록 (자유 메모/`#검수/태그` OK)
2. **분류** — 그룹 다 보면 상단 코드블록 4영역에 정리. 직접 쓰거나 **"○○ 그룹 검수 분석해서 분류해줘"** 요청
   - **1) 전역 규칙** — 모든 챕터 공통 글쓰기 패턴 (conventions에 없으면 신규 후보)
   - **2) 그룹 규칙** — 이 그룹 한정 사실·구조 (메뉴 위치·탭 이름 등)
   - **3) 기존 전역 규칙 누락** — 이미 있는 규칙인데 새어나옴 → 다른 그룹 grep (규칙 추가 X)
   - **4) 확인 필요** — 추측으로 쓴 사실 → 코드·UI 재검증 (잘못 고치면 더 틀림)
   - 그룹 전용 패턴 더 있으면 **5) 이하 그 그룹에만 추가**
3. **누적** — 1·3 + 글로서리 라벨처럼 **전역성 있는 것**은 [[#반영 대기 (검수 누적 → 마감 후 일괄 승격)|반영 대기]] A/B/C로 옮긴다
4. **승격** — 마감 후(or 2~3그룹 더 본 뒤) 반영 대기 → conventions·checklist·글로서리에 **일괄 반영**

> ⚠️ **마감 전엔 conventions/checklist 직접 수정 X.** staging(반영 대기)에만 모으고, 페이지마다 i18n grep(정확성)은 그때그때 돌린다.
