```
시작
  │
코드①  검증 (payload 파싱, 필수조건 존재 확인)
  │
IF/ELSE①  ok?
  ├─ false → 종료(에러: 요청 오류)
  └─ true
       │
      HTTP①  아이템 메타 조회 (DB API, GET/POST)
       │
      코드②  검색조건정규화 (A1)
       │
      HTTP②  유사품목검색 (DB API, Top-10 조회)
       │
      IF/ELSE②  후보 있음?
       ├─ false → 종료(에러: HISTORY_NOT_FOUND)
       └─ true
            │
           코드③  랭킹보정 (A3: 최신성 정렬 + match 판정 + confidence 계산)
            │
           LLM①  추천 근거 문장 생성 (A4, reasons[] — 옵션)
            │
           코드④  최종 조합 (candidates[] 구조 조립)
            │
           HTTP③  결과저장 (A5, DB API POST — 실패해도 응답은 진행)
            │
           코드⑤  Output JSON 조립 (A6)
            │
          종료(성공)
```
