## 배운 것

### Mintlify 정체 명확화
- **라이브러리가 아닌 SaaS 플랫폼** — mintlify.com에서 호스팅 + 자동 빌드/배포 제공
- npm `mintlify` CLI는 **`mintlify dev` 로컬 미리보기 전용**, 정적 빌드 명령 없음 (실제 빌드는 Mintlify Cloud 서버에서만)
- 빌드 엔진 비공개(proprietary) → 자체 호스팅은 Enterprise 플랜만 가능
- git 연동은 **GitHub/GitLab/Bitbucket SaaS만 지원** — Free 플랜도 GitHub 연동 OK, 유료 여부와 무관
- 비슷한 포지션: GitBook, ReadMe.io / 오픈소스 경쟁자: Docusaurus

### Gitolite 정체
- **git의 종류가 아니라 git 위에 얹는 SSH 기반 접근 제어 레이어**
- 권한 관리는 `gitolite-admin` 리포의 `conf/gitolite.conf` 텍스트 파일로
- **웹 UI·이슈/PR·API·webhook 모두 없음** → SaaS 도구(Mintlify, Vercel 등) 자동 연동 불가
- GitLab/Gitea = Gitolite + 웹 UI + 풀스택. Gitolite는 미니멀 변종

### Docusaurus
- Meta 오픈소스 SSG (MIT) — React + MDX 기반
- `npm run build` → `build/` 정적 산출물 → 어디든 정적 호스팅 가능
- i18n·버전 관리·검색 플러그인 내장, Mintlify 대비 사내망 친화적
- 한국어 검색: `@easyops-cn/docusaurus-search-local` (오프라인 OK)

### 정적 사이트 사내 호스팅 옵션
- Docusaurus 산출물은 정적 HTML/CSS/JS → **nginx 필수 아님**
- 대안: **Caddy**(설정 1줄, HTTPS 자동), Apache, `npx serve`, Python `http.server`
- **Docker multi-stage**가 사내망 가장 적합 — node로 빌드 → nginx:alpine으로 서빙, 최종 이미지 ~30MB
- 빌드 머신에 Node 설치 제약 있어도 Docker만 있으면 OK

### 신입의 위임 패턴
- 의사결정 권한 밖 항목(보안 정책·인프라 자원)은 정리 후 위임이 정답
- "정리된 위임" = 사실 조사 + 선택지 + 본인 의견 한 줄 → 의사결정 빠르게 함
- 본인 의견 없이 옵션만 던지면 "본인 생각은?" 되돌아옴
