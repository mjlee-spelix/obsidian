## 배운 것

### PowerShell 5.1 인코딩 함정 ⚠️
- `Get-Content -Raw` + `Set-Content`에 `-Encoding UTF8` 누락 시 한국어 Windows는 **cp949 (시스템 ANSI) 로 읽고 씀**
- BOM 없는 UTF-8 파일을 cp949로 잘못 디코딩 → invalid 바이트가 `?` / `U+FFFD`로 영구 대체 → 다시 어떤 인코딩으로 변환해도 복구 불가
- 우회 방법:
  - 모든 PowerShell 명령에 `-Encoding UTF8` 명시
  - 또는 PS 7 사용 (UTF-8 기본)
  - 또는 `chcp 65001` + `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 설정
  - `.NET` API 직접 호출 시 `[System.Text.UTF8Encoding]::new($false)` 명시
- 본 사고로 SESSION_HISTORY.md 변경 이력 영역 완전 손실 — 복구 불가

### claude code CLI는 nvm 버전마다 별도 설치
- `npm install -g @anthropic-ai/claude-code`는 현재 활성 Node 버전에만 설치됨
- `nvm use 22` 후 `claude` 사용하려면 v22에 별도 설치 필요
- 해결책: 회사 표준 Node 버전에 설치 + nvm 전환 시 항상 같은 버전 사용

### 차트 드로어 보류 결정 — 정보 한 단계 깊게의 본질
- 차트 드로어 = "정보 한 단계 깊게 보기" 메타포
- 이사님 의문: 사용자가 정말 그 깊이를 원하나? 관리자만 필요한 거 아닌가?
- → 보류하고 사용자 피드백 + 관리자 권한 분리 정책 확정 후 재검토
- 우리 spec의 위치: chart-drawer 본문 보존 (재검토 시 base 활용)

### Generated Column으로 JSONB 추출 (마트 설계)
- PostgreSQL: `ALTER TABLE ... ADD COLUMN app_mode TEXT GENERATED ALWAYS AS (details->>'appMode') STORED`
- 자동 채워짐 + 인덱싱 가능 + 쿼리 단순 (`WHERE app_mode = 'chat'`)
- STORED 옵션 권장 (디스크 약간 사용하지만 인덱스 가능)
- audit collector 보강 시 같이 진행 권장

### Materialized View + pg_cron 5분 주기 — 프로덕션 마트 시작점
- 사용자 범위 = 전체 공개로 동시 쿼리 부하 증가 → View로 시작은 위험
- Materialized View + `REFRESH CONCURRENTLY` (UNIQUE INDEX 전제) → 다운타임 0 새로고침
- staleTime 5분과 정합 → 5분 주기 새로고침
- 데이터 양 1억 행 초과 시 → 별도 fact + ETL로 진화
