- 과제1
	- **공통**
		- ccm0080: 부서원 조회, ccm0081: 로그인 아이디로 권한 그룹 조회
		- ccm0080 조회 시, `create_date_time` 이용해서 특정 시점만 가져옴 (배치/수동 조회 시점)
		- ccm0080
			- `data_cat`=10: 부서 이동자, `data_cat`=20: to-be 부서원, `data_cat`=30: as-is 부서원
		- ccm0081
			- `web_authrt_group_id`=`ROLE_RP07`: 기본가입자, `web_authrt_group_id`=`ROLE_RP06`: 일반 사용자

	- **case1: 부서 이동**
		- ccm0080에서 `data_cat=10`의 `orgeh` (=대상자의 to-be 부서) 확인 후 `data_cat=20`&`orgeh=대상자.orgeh`로 to-be 부서원 목록 조회하여 해당 사용자들의 `user_lgn_id` 로 ccm0081에서 권한 목록 조회(권한 그룹 아이디: `web_authrt_group_id`, 조회 조건: `ccm0080.user_lgn_id = ccm0081.user_lgn_id`&`use_yn=Y`), 가장 많은 `web_authrt_group_id`로 권한 산출
			- 대상 식별: `data_cat=10` 행 = AS-IS(`prev_orgeh`) ≠ TO-BE(`orgeh`)인 임직원.
			- 산출 로직 — "TO-BE 부서 최다 보유 권한":
				1. 대상자의 `orgeh`(TO-BE) 확인
				2. CCM0080에서 `data_cat=20 AND orgeh = 대상자.orgeh` → 같은 TO-BE 부서 현재 사용자 목록 추출
				3. 그 사용자들의 `user_lgn_id`로 CCM0081(금일 스냅샷, `use_yn='Y'`) 조회
				4. 부서 내 권한 그룹별 보유 인원수 집계 → 최다 보유 권한(들)을 대상자 개인 권한으로 산출

	- **case2: 부서 이동 & to-be 부서원 부재**
		- ccm0080에서 `data_cat=10`의 orgeh 확인 후 `data_cat=20`&`orgeh=대상자.orgeh` 가 없을 때, 
			- 대상 식별: CASE#1 대상자 중 TO-BE 부서(`orgeh`)에 금일자 현재 사용자가 없는 경우 (= `data_cat=20`에 해당 orgeh 없음).
			- 산출 로직 — "전일 TO-BE 부서 임직원 보유 권한":
				1. CCM0080에서 `data_cat=30 AND prev_orgeh = 대상 TO-BE부서코드` → 전일 그 부서 임직원 목록 추출
				2. 그 임직원들의 `user_lgn_id`로 CCM0081 전일(07-02) 스냅샷 조회
				3. 전일 부서원이 보유했던 권한 목록을 산출 (CASE#1과 동일하게 최다 보유 권한 방식)

	- **case3: 사용자 유형 변경 (기본->일반)**
		- ccm0080에서 `data_cat=10` 이고 `general_rol_yn=Y` 인 대상자의 `user_lgn_id`로 ccm0081에서 권한 목록 조회 및 최다 보유 권한 산출 (대상자의 to-be 부서와 as-is 부서는 동일함)

## 메모
- 과제1 데이터 질의사항
	- case2의 경우, 과제 정의서나 에이전트 설계서에서 'TO-BE 부서에 금일 임직원이 없으면 전일 TO-BE 임직원 보유 권한을 산출' 한다고 적혀있는데 (`이전 스냅샷 기준 data_cat=20의 orgeh`) 참조 데이터에서는 '이전 부서 사용자 목록​'(`data_cat=30의 prev_orgeh`)을 조회한다고 적혀있음. 어떤 기준으로 권한 목록을 조회/산출해야 되는지 확인이 필요.
		- 전자라면, '전일 to-be 임직원'을 어떻게 조회하는지? ccm0080에 데이터가 누적/보존되는지, 테이블 조회 시점에 최신만 유지 되는 건지
	- case3의 경우, `data_cat=30`에 존재하는 `prev_orgeh` 값은 누군가의 AS-IS로 등장한 부서뿐입니다. 그래서 해석(b) `prev_orgeh == t.orgeh`는 타깃의 TO-BE 부서가 (다른 누군가의) AS-IS로도 나타날 때만 결과가 있습니다.
		- `data_cat=30`은 대상자의 AS-IS 부서 기준으로만 적재, TO-BE 부서가 빈 경우 그 부서의 이전 인원 명단을 `data_cat=30`에 어떻게 보장해서 넣어주는지

batch  = max(CCM0080.create_date_time)                 # 이번 실행 수집 배치 (update 아님)

S_now  = snaps[0]      # 최신 백업 = 금일
S_prev = snaps[1]      # 직전 백업 = "전일"  (달력상 어제 아님, 직전 스냅샷)

# ---- 헬퍼 ----
def roles(user, snap):                                 # 특정 시점 보유 권한 집합
    return { r.web_authrt_group_id for r in CCM0081
             if r.user_lgn_id == user
             and r.backup_date_time == snap
             and r.use_yn == 'Y' }

def 최다보유권한(members, snap):                        # 부서원 인원수 기준 최다
    cnt = Counter()
    for u in members: cnt.update( roles(u, snap) )      # 사용자 단위 집계
    if not cnt: return ([], 'NONE')
    mx = max(cnt.values())
    winners = [role for role, n in cnt.items() if n == mx]
    return (winners, 'TIE' if len(winners) > 1 else 'ONE')

# 1. 대상자(data_cat=10) 순회 → CASE 분기
