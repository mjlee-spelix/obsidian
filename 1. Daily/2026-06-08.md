## 배운 것
- **Mintlify→Docusaurus 스타일 복제는 추정 말고 실측** — curl HTML·Tailwind 클래스 px 추출은 구조적으로 틀림(JS 미실행·토큰 의존·상속/pseudo 누락). **살아있는 DOM의 `getComputedStyle` 실측 diff**가 정답. 단 측정 셀렉터가 본문에만 치우치면 헤더 구조(eyebrow·copy 버튼) 누락을 놓침
- **Docusaurus theme swizzle 신규 파일은 dev 서버 재시작 필수** — HMR 안 됨 (기존 파일 수정은 HMR OK)
- **spx-agent 로그인 화면 분기 = 환경변수 2개**:
  - `KEYCLOAK_SIGNIN_REDIRECT` (nginx) — `1`이면 /signin을 KC로 302 리다이렉트, 빈값이면 Dify 폼(백엔드가 KC ROPC로 검증). 로컬에서 KC 화면 뜬 진짜 원인
  - `ENTERPRISE_ENABLED` (백엔드) — true면 `branding.enabled=true`라 카피라이트 숨김 + enterprise SSO. 둘 다 false여야 Dify 폼 + 카피라이트 표시
- **nginx conf는 템플릿(envsubst) → `.env` 바꾸면 컨테이너 `--force-recreate` 해야 반영** (restart 아님)
- **Docker web은 빌드된 이미지** → 소스(로고·컴포넌트) 수정 시 `docker compose up -d --build web` 재빌드 필요
