목표: 각 과제별 구현 로직 문서 작성

배경: 개발 솔루션을 아직 정하지 못함 (dify/코난 솔루션 등), 결정 나기 전까지 과제 구현 로직을 설계하고자 함, 기술 스택도 정해지지 않음 (개발 언어(파이썬/자바 등), db 종류(postgresql, mysql 등) 등)

과제 설명: @3. 프로젝트/서연이화/서연이화 과제 요약.md 

작업 내용 및 순서:
1) 각 과제별 **비즈니스 배경**, **핵심사항**, **액션 플랜** 분석
2) 로직 설계 기준/방향 사용자에게 안내 후 컨펌
- 현재 내용만으로 설계 어렵다면 사용자에게 필요한 정보 요청
3) 각 과제별 로직 작성
- dify, 코난 솔루션 언급 금지 (두 솔루션 사용하지 않음을 가정)
- 현재 작성된 dify/코난 솔루션 기반 구현 방안 고려하지 않음

작성 양식 및 주의 사항:
- 로직 작성 시 아래 2가지의 양식 준수
   - 양식 1) ```블록 코드``` 내 전체 프로세스를 단계별로 -> 표시하여 1줄로 작성
   - 양식 2) 단계별 세부 설명, 어떤 작업/구현을 해야 되는지+어떤 점을 유의해야 되는지 위주로
   - 양식 1, 2 모두 각 과제의 핵심이 되는 구현 작업은 📍 표시
- 작업 효율성을 위해 스킬, 훅, 서브 에이전트 등 활용

산출물
- 1개의 md 문서: 문서 안에 8개의 과제 섹션, 과제 섹션 내에 각 로직 작성
  - 문서 이름 뒤에 (클로드코드/코덱스) 작성

작업 경로
- @3. 프로젝트/서연이화/과제 로직
