- **깃 명령어 지식노트 정리 계획** — 아래 카테고리별로 나눠서 정리하기
	- 🟢 **기본 (이미 쓰고 있는 것)**
		- `git clone` — 원격 저장소 복제 (ssh/https)
		- `git status` — 현재 변경 상태 확인
		- `git add` — 스테이징 (add . vs add 파일명 차이)
		- `git commit` — 커밋 (-m 메시지, --amend 수정)
		- `git push` — 원격에 올리기 (-u origin 브랜치)
		- `git pull` — 원격에서 받기 (fetch+merge 차이도)
		- `git checkout` — 브랜치 이동, 파일 되돌리기
		- `git branch` — 브랜치 생성/삭제/목록
		- `git stash` — 임시 저장 (stash pop, stash list)
	- 🟡 **꼭 알아야 하는데 헷갈리기 쉬운 것**
		- `git switch` / `git restore` — checkout 대체 명령어 (최신 방식)
		- `git merge` vs `git rebase` — 브랜치 합치기 차이
		- `git fetch` — pull 안 하고 원격 정보만 가져오기
		- `git log` — 커밋 이력 보기 (--oneline, --graph 옵션)
		- `git diff` — 변경 내용 비교 (staged/unstaged 차이)
		- `git reset` — 커밋 되돌리기 (soft/mixed/hard 차이 중요!)
		- `git revert` — 커밋 취소 (reset과 차이: 이력 보존)
		- `.gitignore` — 추적 제외 파일 설정
	- 🔴 **실무에서 만나면 당황하는 것**
		- `git cherry-pick` — 다른 브랜치에서 특정 커밋만 가져오기
		- `git rebase -i` — 커밋 정리 (squash, 메시지 수정)
		- `git tag` — 버전 태그 달기
		- `git remote` — 원격 저장소 관리
		- merge conflict 해결 방법
		- HEAD, origin, upstream 개념 정리
	- 💡 **정리 방식**: 카테고리별로 지식노트 여러 개로 나눌지, 하나에 다 넣을지 결정하기
		- 추천: 큰 주제별로 2~3개 나누기 (기본 워크플로우 / 브랜치 전략 / 되돌리기&충돌 해결)

- **리눅스/커맨드 명령어 지식노트 정리 계획** — 서버 작업할 때 필요한 것 위주로
	- 🟢 **파일/디렉토리 기본**
		- `ls` — 파일 목록 보기 (-la 옵션 중요)
		- `cd` — 디렉토리 이동 (~, .., - 차이)
		- `pwd` — 현재 경로 확인
		- `mkdir` — 디렉토리 생성 (-p 중첩 생성)
		- `cp` — 복사 (-r 폴더 복사)
		- `mv` — 이동/이름 변경
		- `rm` — 삭제 (-rf 주의!)
		- `touch` — 빈 파일 생성
	- 🟡 **파일 내용 확인/검색**
		- `cat` — 파일 전체 출력
		- `head` / `tail` — 앞/뒤 일부만 보기 (tail -f 로그 실시간 확인!)
		- `grep` — 텍스트 검색 (-r 재귀, -i 대소문자 무시)
		- `find` — 파일 찾기 (이름, 크기, 날짜 기준)
		- `wc` — 줄/단어/글자 수 세기
		- `vi` / `vim` / `nano` — 터미널 텍스트 편집기 (vi 기본 조작법은 필수)
	- 🟢 **권한/소유자**
		- `chmod` — 권한 변경 (755, 644 등 숫자 의미)
		- `chown` — 소유자 변경
		- `sudo` — 관리자 권한 실행
	- 🟡 **프로세스/시스템**
		- `ps` — 프로세스 목록 (ps aux)
		- `top` / `htop` — 실시간 시스템 모니터링
		- `kill` / `kill -9` — 프로세스 종료
		- `df` — 디스크 용량 확인 (-h 사람이 읽기 쉬운 단위)
		- `du` — 폴더별 용량 확인
		- `free` — 메모리 확인
	- 🟡 **네트워크**
		- `curl` — HTTP 요청 보내기 (API 테스트에 필수)
		- `wget` — 파일 다운로드
		- `ping` — 연결 확인
		- `netstat` / `ss` — 포트/연결 상태 확인
		- `scp` — 서버 간 파일 복사
		- `ssh` — 원격 서버 접속
	- 🔴 **실무에서 자주 쓰는 조합/고급**
		- 파이프 `|` — 명령어 연결 (예: `ps aux | grep python`)
		- 리다이렉션 `>`, `>>` — 출력을 파일로 저장
		- `&&`, `||` — 명령어 체이닝
		- `nohup` / `&` — 백그라운드 실행
		- `tar` / `zip` — 압축/해제
		- `systemctl` — 서비스 관리 (start, stop, status, enable)
		- `journalctl` — 시스템 로그 확인
		- `crontab` — 스케줄 작업 등록
	- 💡 **정리 방식**: 깃과 마찬가지로 2~3개 나누기 추천
		- 추천: 파일/디렉토리 기본 / 프로세스·시스템·네트워크 / 실무 조합·팁

- **도커(Docker) 명령어 지식노트 정리 계획** — dify 운영하면서 매일 쓰는 것 위주로
	- 🟢 **컨테이너 기본**
		- `docker ps` — 실행 중인 컨테이너 목록 (-a 전체)
		- `docker start` / `stop` / `restart` — 컨테이너 시작/중지/재시작
		- `docker logs` — 컨테이너 로그 보기 (-f 실시간, --tail 줄 수 지정)
		- `docker exec` — 실행 중인 컨테이너 안에서 명령 실행 (-it bash로 접속)
		- `docker rm` — 컨테이너 삭제
		- `docker inspect` — 컨테이너 상세 정보 (IP, 볼륨, 환경변수 등)
	- 🟢 **이미지 관련**
		- `docker images` — 이미지 목록
		- `docker pull` — 이미지 다운로드
		- `docker build` — Dockerfile로 이미지 빌드 (-t 태그 지정)
		- `docker rmi` — 이미지 삭제
		- `docker tag` — 이미지 태그 변경
	- 🟡 **Docker Compose (dify 운영 핵심!)**
		- `docker compose up` — 전체 서비스 시작 (-d 백그라운드)
		- `docker compose down` — 전체 서비스 중지/삭제 (-v 볼륨까지 삭제 주의!)
		- `docker compose ps` — compose 서비스 상태 확인
		- `docker compose logs` — 특정 서비스 로그 (예: `docker compose logs api -f`)
		- `docker compose restart` — 특정 서비스만 재시작
		- `docker compose pull` — 이미지 업데이트
		- `docker compose exec` — 특정 서비스 컨테이너 접속
		- `docker-compose.yml` 구조 이해 (services, volumes, networks, environment)
	- 🟡 **볼륨/네트워크**
		- `docker volume ls` — 볼륨 목록
		- `docker volume inspect` — 볼륨 상세 (데이터 실제 경로 확인)
		- `docker network ls` — 네트워크 목록
		- 컨테이너 간 통신 원리 (같은 네트워크 안에서 서비스명으로 접근)
	- 🔴 **트러블슈팅/실무**
		- `docker system prune` — 안 쓰는 리소스 일괄 정리 (디스크 부족할 때!)
		- `docker stats` — 컨테이너별 CPU/메모리 실시간 모니터링
		- `docker cp` — 컨테이너 ↔ 호스트 파일 복사
		- 컨테이너가 안 뜰 때 디버깅 순서 (logs → inspect → exec)
		- 환경변수 `.env` 파일 관리
		- 포트 매핑 (`-p 호스트:컨테이너`) 이해
	- 💡 **정리 방식**: 2개 추천
		- 컨테이너·이미지 기본 / Docker Compose·실무 트러블슈팅
