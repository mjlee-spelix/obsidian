## 배운 것
- **어노테이션 답변 = 대화형 앱 전용** — 챗봇·에이전트·채팅 플로우만 가능. 워크플로우·완성형은 진입점 자체 없음(탭 슬라이더 미표시 + 기능 패널 `isChatMode` 조건). 활성화 주 경로는 "로그 및 어노테이션" 탭(문서의 "오케스트레이트→기능 추가"는 채팅앱 한정 대체 경로)
- **Dify 모니터링은 로그·통계 둘 다 앱 모드별로 다름** — 로그는 테이블 컬럼(워크플로우=별도 UI·트리거출처 / 채팅 플로우만 Status), 통계는 차트 세트 자체(완성형/채팅류/워크플로우)가 다름. messages 8종 vs workflow_runs 4종, 워크플로우는 금액 없이 토큰만
- **Dify 로그 "개인정보 보호" 문구 = 절반만 실제 기능** — 보관기간(env `WORKFLOW_LOG_RETENTION_DAYS`/CLI)·접근제어(워크스페이스 RBAC 종속)는 실재, 익명화·처리방침 게시는 제품 기능 아님(원본 일반론) → 문서에서 "운영·법적 고려사항" 분리 필요
- **"기능 없음"은 클릭보다 코드 grep이 확실** — 익명화처럼 부재를 증명할 땐 화면 클릭으로 확신 어려움. 제품 소스 직접 조사가 더 빠르고 단정적
- **큰 진행 문서는 라이브/이력 계층 분리** — 상태(라이브)와 시간순 로그(이력)를 한 파일에 두면 비대화·stale 발생. 상단 "한눈에" 요약 블록 + 이력은 archive 분리 + "세션 끝에 요약 먼저 갱신" 규칙으로 방지. (이번에 Get Started가 실제 완료인데 "임시 1p"로 stale였던 사고 계기)
- **기존 지식노트 재활용 의식** — 모니터링 통계 차트 차이는 4월에 이미 [[4. 지식노트/Dify - 앱 통계 UI 구조.md]]에 정리돼 있었음. 새로 파기 전에 볼트 검색 먼저
- **favicon 구조: SVG vs 래스터** — Docusaurus는 SVG 한 파일이라 교체 간단 / 제품 앱(Next.js)은 `icon-*.png`·`favicon.ico`·`apple-touch`·`manifest.json` 다수 래스터라 각 크기 재생성 필요. ICO는 PNG를 임베드 가능(헤더+엔트리+PNG바이트), `sharp`로 SVG→투명 PNG 렌더. 투명 배경은 탭엔 OK지만 iOS 홈화면은 검은 배경 채움
- **manifest.json = PWA 앱 이름/아이콘** — 설치 다이얼로그·홈화면 라벨·스플래시에 쓰임. 브라우저 탭 제목(`<title>`)과는 별개. 리브랜딩 시 favicon만 바꾸고 `name`/`short_name` 놓치기 쉬움
