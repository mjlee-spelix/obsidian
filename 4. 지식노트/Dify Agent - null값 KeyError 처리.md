# Dify Agent - null값 KeyError 처리

## 핵심
- 도구(Tool) 실행 결과가 `null`일 때 에이전트가 존재하지 않는 키를 참조해 `KeyError: ""` 발생
- 프롬프트 지침 추가 + 도구 워크플로우 자체에서 null 처리 두 가지 방법으로 대응

## 상세

### 에러 상황
```
PluginInvokeError: KeyError: ""
```
쿼리 조건에 맞는 데이터가 없을 때(결과 null) 에이전트가 답변 생성 단계에서 발생.

### 원인 후보
1. Dify 노드 설정 내 **이름이 비어 있는 출력 변수(Output Variable)** 존재
2. 플러그인 응답 객체 구조와 에이전트의 참조 설정 불일치

### 해결 방법

#### 방법 1. 프롬프트 지침 추가 (1차 대응)
```
데이터가 null이거나 조회 결과가 없는 경우, 에러를 발생시키지 말고
"해당 조건에 맞는 데이터가 없습니다."라고 안내하세요.
```
→ 즉각 적용 가능하나 간헐적으로 재발할 수 있음

#### 방법 2. 도구 워크플로우에 null 처리 노드 추가 (근본 해결)
도구로 등록된 워크플로우 자체에 조건 분기 추가:
- 결과가 없을 경우 → `"검색 결과가 없습니다"` 텍스트 반환 노드 연결
- 에이전트가 빈 값 대신 항상 유효한 문자열을 받도록 보장
