# 리눅스 - 실무 조합·팁

## 핵심
- 파이프(`|`)와 리다이렉션(`>`)을 쓰면 명령어를 조합해서 훨씬 강력하게 활용 가능
- `systemctl`은 서비스 관리, `journalctl`은 시스템 로그 확인 — 서버 운영의 핵심
- `nohup`이나 `&`으로 백그라운드 실행하면 SSH 끊어도 프로세스 유지
- `tar`/`zip` 압축과 `crontab` 예약 실행도 실무에서 자주 사용

## 상세

### 파이프 `|` — 명령어 연결

앞 명령어의 출력을 뒤 명령어의 입력으로 전달

```bash
# 자주 쓰는 조합들
ps aux | grep python               # 프로세스 중 python 찾기
ls -la | grep ".log"               # 파일 중 .log 포함된 것만
cat 파일.txt | wc -l               # 파일 줄 수 세기
du -sh * | sort -rh | head -5      # 가장 큰 폴더/파일 5개
docker ps | grep dify              # dify 관련 컨테이너 찾기
history | grep "docker compose"    # 이전에 쳤던 docker compose 명령 찾기
```

### 리다이렉션 `>`, `>>` — 출력을 파일로

```bash
echo "hello" > 파일.txt            # 파일에 덮어쓰기 (기존 내용 삭제!)
echo "world" >> 파일.txt           # 파일에 추가 (이어쓰기)
ps aux > process_list.txt          # 프로세스 목록을 파일로 저장
명령어 > /dev/null 2>&1            # 출력 전부 버리기 (조용히 실행)
```

| 기호 | 동작 | 주의 |
|------|------|------|
| `>` | 덮어쓰기 | 기존 내용 날아감! |
| `>>` | 이어쓰기 | 안전 |
| `2>` | 에러만 파일로 | 표준 에러 리다이렉션 |
| `2>&1` | 에러도 같은 곳으로 | 에러+출력 합치기 |

### 명령어 체이닝 `&&`, `||`, `;`

```bash
mkdir 폴더 && cd 폴더              # 앞이 성공하면 뒤 실행
ping -c 1 server || echo "실패"    # 앞이 실패하면 뒤 실행
명령어1 ; 명령어2                   # 성공/실패 상관없이 둘 다 실행
```

| 기호 | 조건 | 용도 |
|------|------|------|
| `&&` | 앞 성공 시 | 의존 관계 있을 때 |
| `\|\|` | 앞 실패 시 | 실패 시 대안 실행 |
| `;` | 무조건 | 순서만 중요할 때 |

### 백그라운드 실행

#### nohup — SSH 끊어도 유지

```bash
nohup python app.py &              # 백그라운드 실행 (로그: nohup.out)
nohup python app.py > app.log 2>&1 &  # 로그 파일 지정
```

- `nohup` 없이 `&`만 쓰면 SSH 끊으면 같이 죽음
- `nohup`으로 실행하면 터미널 닫아도 계속 실행

#### 백그라운드 관리

```bash
jobs                               # 현재 백그라운드 작업 목록
fg %1                              # 1번 작업을 포그라운드로
bg %1                              # 1번 작업을 백그라운드로
Ctrl+Z                             # 현재 작업 일시 정지 → bg로 백그라운드 전환 가능
```

### tar / zip — 압축

```bash
# tar.gz 압축
tar -czf 압축파일.tar.gz 폴더/          # 압축하기
tar -xzf 압축파일.tar.gz               # 압축 풀기
tar -xzf 압축파일.tar.gz -C /목적지/    # 특정 위치에 풀기
tar -tzf 압축파일.tar.gz               # 내용만 확인 (풀지 않고)

# zip
zip -r 압축파일.zip 폴더/              # zip 압축
unzip 압축파일.zip                     # zip 해제
unzip 압축파일.zip -d /목적지/          # 특정 위치에 해제
```

tar 옵션 외우기:
| 옵션 | 의미 |
|------|------|
| `-c` | create (생성) |
| `-x` | extract (해제) |
| `-z` | gzip 압축 |
| `-f` | 파일명 지정 |
| `-v` | 진행 상황 출력 |
| `-t` | 내용 보기 |

### systemctl — 서비스 관리

```bash
systemctl status nginx             # 서비스 상태 확인
systemctl start nginx              # 시작
systemctl stop nginx               # 중지
systemctl restart nginx            # 재시작
systemctl enable nginx             # 부팅 시 자동 시작 설정
systemctl disable nginx            # 자동 시작 해제
systemctl list-units --type=service # 전체 서비스 목록
```

### journalctl — 시스템 로그 확인

```bash
journalctl -u nginx                # 특정 서비스 로그
journalctl -u nginx -f             # 실시간 로그 (tail -f처럼)
journalctl -u nginx --since "1 hour ago"  # 최근 1시간
journalctl -u nginx --since today  # 오늘 것만
journalctl --disk-usage            # 로그가 차지하는 디스크 크기
```

### crontab — 예약 실행

```bash
crontab -e                         # 편집
crontab -l                         # 현재 등록된 목록 보기
```

크론 표현식:
```
*    *    *    *    *    명령어
분   시   일   월   요일
(0-59)(0-23)(1-31)(1-12)(0-7, 0과7=일요일)
```

예시:
```bash
# 매일 새벽 3시에 백업
0 3 * * * /home/user/backup.sh

# 5분마다 실행
*/5 * * * * /home/user/check.sh

# 매주 월요일 오전 9시
0 9 * * 1 /home/user/weekly.sh

# 매월 1일 자정
0 0 1 * * /home/user/monthly.sh
```

### 자주 쓰는 실전 조합 모음

```bash
# 로그에서 에러만 찾기
grep -i "error" /var/log/syslog | tail -20

# 특정 포트 사용 프로세스 찾기
ss -tlnp | grep 8080

# 큰 파일 찾아서 정리
find /var/log -name "*.log" -size +100M

# 디스크 사용량 큰 순 정렬
du -sh /var/* | sort -rh | head -10

# 서비스 로그 실시간 확인하면서 에러만 필터
journalctl -u nginx -f | grep -i error

# 파일 개수 세기
find . -type f | wc -l
```
