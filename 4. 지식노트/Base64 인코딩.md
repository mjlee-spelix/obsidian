# Base64 인코딩

## 핵심
- 이진 데이터(이미지, 파일 등)를 64개의 ASCII 문자로 변환하는 인코딩 방식
- 텍스트 기반 시스템(HTML, JSON 등)에 이미지를 직접 포함시킬 때 사용
- 변환 시 원본보다 용량이 약 **33% 증가**

## 상세

### 왜 쓰나?
- 시스템마다 문자 처리 방식이 달라 이진 데이터를 그대로 전송하면 깨질 수 있음
- Base64로 변환하면 어떤 시스템에서도 안전하게 전달 가능
- 이미지 파일 없이 텍스트 문서 안에 이미지 데이터를 직접 삽입 가능

### 사용 문자

| 구분 | 포함 문자 |
|---|---|
| 알파벳 | A-Z (26개), a-z (26개) |
| 숫자 | 0-9 (10개) |
| 기호 | `+`, `/` (2개) |
| 패딩 | `=` (길이 맞춤용) |

### Dify/n8n에서의 활용
- <mark style="background: #FFB8EBA6;">코드 노드에서 이미지를 직접 반환 못할 때, Base64 문자열로 변환 후 String으로 전달</mark>
- HTML/마크다운에서 활용:
  ```
  ![차트](data:image/png;base64,iVBORw0KGgo...)
  ```
- `base64_codec` 플러그인으로 Base64 → 실제 파일 객체로 변환 가능

### 장단점
|        | 내용                                            |
| ------ | --------------------------------------------- |
| **장점** | 이미지 파일을 따로 관리할 필요 없이 전송 간편                    |
| **단점** | 용량 약 33% 증가, 문자열이 길어져 LLM context 소모 이슈 발생 가능 |
