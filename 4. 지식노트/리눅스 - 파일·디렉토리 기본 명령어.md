# 리눅스 - 파일·디렉토리 기본 명령어

## 핵심
- 리눅스 서버에서 파일/폴더를 다루는 가장 기초적인 명령어 모음
- `ls`, `cd`, `cp`, `mv`, `rm`만 확실히 알면 파일 관리의 90%는 해결
- 파일 내용 확인은 `cat`(전체), `head`/`tail`(일부), `grep`(검색)으로 나뉨
- `vi` 기본 조작은 서버 작업할 때 반드시 필요 — 최소한 저장/나가기는 외워두기

## 상세

### 디렉토리 이동/확인

```bash
pwd                    # 현재 경로 확인 (Print Working Directory)
cd /home/user          # 절대 경로로 이동
cd ..                  # 상위 디렉토리로
cd ~                   # 홈 디렉토리로 (= cd)
cd -                   # 직전 디렉토리로 돌아가기 (편리!)
```

### ls — 파일 목록 보기

```bash
ls                     # 기본 목록
ls -l                  # 상세 정보 (권한, 크기, 날짜)
ls -la                 # 숨김 파일(.으로 시작)까지 전부
ls -lh                 # 파일 크기를 사람이 읽기 쉽게 (KB, MB)
ls -lt                 # 시간순 정렬 (최신이 위)
```

`ls -la` 출력 읽는 법:
```
drwxr-xr-x  2 user group 4096 Apr 22 10:30 폴더명
-rw-r--r--  1 user group  256 Apr 22 10:30 파일명
│└─┬──┘└┬─┘
│  │    └── 기타 권한
│  └─────── 그룹 권한
└────────── 소유자 권한 (d=디렉토리, -=파일)
```

### 파일/디렉토리 생성·복사·이동·삭제

```bash
# 생성
mkdir 폴더명                    # 디렉토리 생성
mkdir -p a/b/c                 # 중간 경로까지 한 번에 생성
touch 파일명.txt                # 빈 파일 생성

# 복사
cp 원본.txt 사본.txt            # 파일 복사
cp -r 원본폴더/ 사본폴더/        # 폴더 복사 (-r 필수!)

# 이동/이름 변경
mv 파일.txt 새이름.txt           # 이름 변경
mv 파일.txt /다른/경로/          # 파일 이동
mv 폴더/ /다른/경로/             # 폴더 이동 (-r 필요 없음)

# 삭제
rm 파일.txt                    # 파일 삭제
rm -r 폴더/                    # 폴더 삭제
rm -rf 폴더/                   # 강제 삭제 (확인 없이) ⚠️ 매우 주의!
```

> ⚠️ `rm -rf`는 복구 불가! 특히 `rm -rf /`는 시스템 전체 삭제 — 절대 치면 안 됨

### 파일 내용 확인

```bash
cat 파일.txt                   # 파일 전체 출력
cat -n 파일.txt                # 줄 번호와 함께 출력

head 파일.txt                  # 앞 10줄만
head -20 파일.txt              # 앞 20줄만
tail 파일.txt                  # 뒤 10줄만
tail -20 파일.txt              # 뒤 20줄만
tail -f 파일.log               # 실시간 로그 모니터링 (Ctrl+C로 종료)
```

- `tail -f`는 서버 로그 볼 때 필수! (예: `tail -f /app/logs/server.log`)

### grep — 텍스트 검색

```bash
grep "검색어" 파일.txt           # 파일에서 검색
grep -i "error" 파일.log        # 대소문자 무시
grep -r "검색어" ./             # 하위 폴더까지 재귀 검색
grep -n "검색어" 파일.txt        # 줄 번호와 함께
grep -c "error" 파일.log        # 매칭 개수만 출력
grep -v "제외할것" 파일.txt      # 해당 문자열이 없는 줄만 출력
```

### find — 파일 찾기

```bash
find . -name "*.log"           # 현재 디렉토리에서 .log 파일 찾기
find / -name "server.log"      # 전체 시스템에서 찾기
find . -type d -name "logs"    # 디렉토리만 찾기
find . -size +100M             # 100MB 이상 파일 찾기
find . -mtime -7               # 최근 7일 내 수정된 파일
```

### wc — 줄/단어/글자 수 세기

```bash
wc 파일.txt                    # 줄 수, 단어 수, 바이트 수
wc -l 파일.txt                 # 줄 수만
```

### vi/vim — 터미널 편집기 기본 조작

```
vim 파일.txt                   # 파일 열기
```

| 모드 | 진입 | 설명 |
|------|------|------|
| 일반 모드 | `Esc` | 이동, 삭제, 복사 |
| 입력 모드 | `i` | 텍스트 편집 |
| 명령 모드 | `:` | 저장, 나가기 등 |

**최소한 이것만 외우기:**

| 키 | 동작 |
|-----|------|
| `i` | 편집 시작 |
| `Esc` | 편집 종료 (일반 모드로) |
| `:w` | 저장 |
| `:q` | 나가기 |
| `:wq` | 저장하고 나가기 |
| `:q!` | 저장 안 하고 강제 나가기 |
| `dd` | 한 줄 삭제 |
| `yy` → `p` | 한 줄 복사 → 붙여넣기 |
| `/검색어` | 검색 (n으로 다음 결과) |
| `u` | 실행 취소 (undo) |

### 권한/소유자

```bash
# 권한 변경
chmod 755 스크립트.sh           # rwxr-xr-x (실행 가능)
chmod 644 파일.txt             # rw-r--r-- (읽기 전용)
chmod +x 스크립트.sh            # 실행 권한 추가

# 소유자 변경
chown user:group 파일.txt       # 소유자와 그룹 변경
chown -R user:group 폴더/      # 폴더 전체 재귀 변경

# 관리자 권한
sudo 명령어                    # 관리자 권한으로 실행
sudo su                       # root 사용자로 전환
```

권한 숫자 의미:
```
r(읽기)=4  w(쓰기)=2  x(실행)=1

755 = rwx(7) r-x(5) r-x(5) → 소유자:전부, 그룹/기타:읽기+실행
644 = rw-(6) r--(4) r--(4) → 소유자:읽기+쓰기, 그룹/기타:읽기만
```
