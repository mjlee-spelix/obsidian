## 논의 내용
- SAP 에이전트는 SAP 검색 + Salesforce를 도구로 만들어 에이전트에 연결하는 구조로 구현
- Dify Marketplace는 온프레미스 환경에서도 사용 가능. 유료 플러그인 불가, 무료/오픈소스만 허용. 개인 배포 오픈소스는 신중히 사용할 것
- SERP API → Google Search API로 대체하는 방향으로 결정
- `gpt-oss:120b`는 40번 서버의 vLLM에서 운영 중. GPU 최소 2장 이상 필요
- LLM 중간 과정 캡처 가능 여부 확인 필요. Qwen vs GPT 비교 필요. 모델별 제약 사항 및 적합한 사용 시나리오 사전 파악 필요
- 차트 생성 엔진은 현재 클라이언트 사이드에서 이미지 생성 중. 당장 Dify 이관 불필요
- Dify Human Input 노드 활용 방안 탐색 필요. Human Input 포함 워크플로우를 도구로 만들어 에이전트에게 넘기는 방식 검토. 순차 워크플로우에서 HITL 삽입 시점은 미지수
- 향후 통합 UI에서 `legacy / agent` 탭 2개 제거 → 통합 챗봇 1개 + 개별 챗봇 다수 형태로 개편 예정

## 결정 사항
- Dify Marketplace 무료/오픈소스 플러그인만 사용 허용
- Search API를 Google Search API로 전환
- 차트 생성 엔진 이관은 현재 고려하지 않음
